# DevShowcase API

API REST desenvolvida para a disciplina de **Programação Backend**, utilizando Java e Spring Boot.

## Tecnologias

* Java 21
* Spring Boot 4.1.1
* PostgreSQL
* Spring Data JPA
* Swagger / OpenAPI
* Docker
* Render

## Funcionalidades

* Perfis
* Projetos
* Tecnologias
* Avaliações
* Upvotes
* Paginação e filtros
* Validação de dados
